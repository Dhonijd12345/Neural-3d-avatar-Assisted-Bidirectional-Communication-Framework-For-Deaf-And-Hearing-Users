## 📖 Overview

Communication between Deaf and Hearing individuals often requires the presence of a human interpreter. This project provides an **AI-powered Bidirectional Communication Framework** that enables real-time communication between Deaf and Hearing users using **Computer Vision, Machine Learning, Speech Recognition, Text-to-Speech, and a 3D Avatar**.

The system recognizes sign language gestures, converts them into readable text, translates spoken language into text, and presents the output through an interactive 3D avatar, creating a seamless communication experience.

# 🏗️ System Architecture

```
          Deaf User
               │
               ▼
      Webcam / Camera Input
               │
               ▼
      Gesture Recognition
     (OpenCV + MediaPipe)
               │
               ▼
     Machine Learning Model
               │
               ▼
         Predicted Text
               │
        ┌──────┴──────┐
        ▼             ▼
  Text-to-Speech   3D Avatar
        │             │
        ▼             ▼
     Hearing User   Visual Output


 Hearing User
        │
        ▼
 Speech Recognition
        │
        ▼
      Text Output
        │
        ▼
   3D Avatar Signs
        │
        ▼
      Deaf User
```

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/Dhonijd12345/Neural-3d-avatar-Assisted-Bidirectional-Communication-Framework-For-Deaf-And-Hearing-Users.git
```

Move into project directory

```bash
cd Neural-3d-avatar-Assisted-Bidirectional-Communication-Framework-For-Deaf-And-Hearing-Users
```

Install dependencies

```bash
pip install -r requirements.txt
```

```bash
python main.py
```
