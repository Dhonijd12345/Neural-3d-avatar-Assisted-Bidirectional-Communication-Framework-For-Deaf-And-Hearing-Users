# Code of Conduct

## Neural 3D Avatar-Assisted Bidirectional Communication Framework

We are committed to maintaining a welcoming, respectful, inclusive, and constructive environment for everyone participating in this project.

This Code of Conduct follows the general principles of the widely used Contributor Covenant.

---

## 🌟 Expected Behavior

Examples of positive behavior include:

- Treating everyone with respect.
- Communicating constructively.
- Welcoming different perspectives.
- Providing useful technical feedback.
- Respecting different levels of experience.
- Supporting collaborative learning.
- Focusing on technical issues rather than individuals.

---

## 🚫 Unacceptable Behavior

The following behavior is not acceptable:

- Harassment.
- Discrimination.
- Personal attacks.
- Threats or intimidation.
- Insulting or derogatory comments.
- Publishing private information without permission.
- Trolling or deliberate disruption.
- Unwanted sexualized behavior.
- Creating a hostile or unsafe environment.

---

## 💬 Technical Discussions

Technical disagreements are normal.

When disagreements happen:

1. Focus on technical evidence.
2. Explain your reasoning.
3. Respect alternative approaches.
4. Avoid personal criticism.
5. Work toward a constructive solution.

---

## 🤝 Contribution Standards

Contributors should:

- Follow `CONTRIBUTING.md`.
- Keep pull requests focused.
- Write clear commit messages.
- Protect sensitive information.
- Respect other contributors.
- Provide constructive feedback.

---

## 🛡️ Enforcement

Project maintainers may take appropriate action when this Code of Conduct is violated.

Possible actions include:

- Requesting behavior changes.
- Removing inappropriate content.
- Closing discussions.
- Rejecting contributions.
- Restricting participation where necessary.

---

## 📢 Reporting

If you experience or observe unacceptable behavior, contact the project maintainer privately.
