# Security Policy

## Neural 3D Avatar-Assisted Bidirectional Communication Framework

Security and responsible handling of user information are important for this accessibility-focused project.

---

## 🛡️ Supported Version

| Version | Support |
|---|---|
| 1.0.x | ✅ Supported |
| Older versions | ⚠️ Best effort |

---

## 🔑 Sensitive Information

Never commit:

- API keys
- Passwords
- Authentication tokens
- Private certificates
- Database credentials
- Personal information
- Private datasets
- Confidential user recordings

---

## 👤 User Privacy

Because this project processes communication inputs such as camera and speech data:

- Process only authorized data.
- Avoid storing unnecessary personal information.
- Do not publish private recordings.
- Use anonymized or synthetic data for demonstrations whenever possible.
- Follow applicable privacy requirements when deploying the system.

---

## 🎥 Camera and Audio Data

Camera and microphone functionality should only be used with appropriate user awareness and permission.

Do not collect, store, or distribute another person's:

- Video
- Audio
- Images
- Voice recordings
- Personal information

without appropriate authorization.

---

## 🤖 AI/ML Security

When modifying the machine-learning pipeline:

- Validate input data.
- Protect model files from unauthorized modification.
- Avoid exposing private training data.
- Validate model outputs.
- Test unexpected inputs.
- Monitor model behavior during deployment.

---
